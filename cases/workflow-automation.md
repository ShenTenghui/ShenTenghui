# 业务流程自动化

[← 返回主页](../README.md)

围绕跨系统、规则密集且需要人工复核的业务，将零散操作组织为可执行的工作流。案例覆盖电商价格核验、询盘报价与社媒运营。

## 代表场景

| 场景 | 原有业务需求 | 应用承接的任务 |
| --- | --- | --- |
| 电商价格核验 | 核对 ERP、电商平台中的价格与 Excel 基准是否一致 | 跨系统查询、差异比对与结果回报 |
| 询盘报价 | 从客户会话中识别需求，匹配商品并按业务规则组织报价 | 需求提取、商品检索、报价规则与信息补全 |
| 社媒运营 | 内容发布、咨询处理与线索整理分散在不同环节 | 内容生成与发布、线索识别、运营日报及执行状态管理 |

## 工作流组织

业务任务 → 获取信息 → 按业务规则处理 → 校验与复核 → 结果回报。

需要人工确认的任务在校验与复核后交由人员确认，再进行结果回报。

价格核验以客户提供的 Excel 为基准，连接 ERP 与电商平台查询，定位价格差异。询盘报价则把会话理解、商品匹配、信息补全和发送前校验连接起来。社媒项目通过可视化界面呈现任务及执行状态。

业务规则与人工确认是流程的重要组成部分：价格差异、商品匹配与发送对象等关键环节需要能被检查，自动处理结果需要回到业务人员的判断与后续操作中。

## 参与环节

客户沟通、业务 SOP 与流程梳理、功能范围和验收要求、方案讨论、功能实施、测试验收及上线交付。

## 交付情况

上述客户项目已交付使用，价格核验应用持续用于客户日常业务。本页归纳不同客户场景中的流程设计与交付经验。
